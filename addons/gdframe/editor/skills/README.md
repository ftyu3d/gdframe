# GDFrame Cursor Skills

源：本目录 `*/SKILL.md`。启用 / 重载插件时覆盖到工程 `res://.cursor/skills/<name>/SKILL.md`，勿手改副本。

| Skill | 用途 |
|-------|------|
| [gdframe-framework](gdframe-framework/SKILL.md) | 通用 GDScript 书写规范（玩法与框架都适用） |
| [gdframe-addon](gdframe-addon/SKILL.md) | 仅编辑 `addons/gdframe` 或 `addons/gdframe_<id>`：编辑器目录、扩展槽位、文档与版本 |
| [gdframe-ui](gdframe-ui/SKILL.md) | `gdframe_project/ui` 界面约定与模板 |

改 `editor/README.md` 章节时同步改正 skills 内链接。本仓库开发时同步到根 `.cursor/skills/`，或以 addons 启用插件自动同步。
